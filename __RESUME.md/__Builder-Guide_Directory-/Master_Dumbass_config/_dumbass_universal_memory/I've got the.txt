  Architecture decision — Supabase
  Free, not self-host:
  - The `local-brain-no-mcp` recipe
  proves self-hosted Supabase works,
   but needs ~8GB RAM / ~5GB disk
  and its `upsert_thought(p_content,
   p_embedding, p_metadata)`
  signature is **incompatible** with
   every OB1 component that calls
  `rpc("upsert_thought",{p_content,p
  _payload})`. Its README claim that
   "cloud recipes work with base-URL
   swap" is **false** for that RPC.
  - Supabase Free gives unlimited
  PostgREST API requests but only
  **500k Edge Function
  calls/month**. One recipe measured
   1.83M invocations/week from 4 MCP
   functions because each MCP tool
  call ≈ 4 HTTP invocations.
  - **Therefore OmniRoute must hit
  PostgREST RPCs directly**
  (match_thoughts / agent-memory
  tables with the service key) and
  compute embeddings itself — never
  route per-call recall through the
  MCP edge function or
  agent-memory-api edge fn, or it
  burns the quota.
