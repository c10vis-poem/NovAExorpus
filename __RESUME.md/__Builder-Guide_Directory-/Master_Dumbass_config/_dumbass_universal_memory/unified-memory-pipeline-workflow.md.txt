3. Local Setup & Execution Commands
Step 1: Install & Configure Core Services
# 1. Install OmniRoute, Mem0 MCP, and CRG globally
npm install -g omniroute @mem0/mcp code-review-graph@latest


# 2. Install Graphify (ensure uv or pipx in Debian proot/Linux)
pipx install graphifyy
pipx install "notebooklm-py[browser]"


# 3. Create Vault Directory Trees
mkdir -p ~/vault/notes ~/vault/sources ~/vault/memories/episodic ~/vault/memories/static ~/.claude/output-styles ~/.claude/scripts
Step 2: Wire Claude Code Output Style & Interceptor Hook
# Copy router guard output style
cp aesop-xi/tools/output-styles/router-guard.md ~/.claude/output-styles/router-guard.md


# Copy smart grep interceptor and make executable
cp aesop-xi/tools/smart-grep-hook.sh ~/.claude/scripts/smart-grep-hook.sh
chmod +x ~/.claude/scripts/smart-grep-hook.sh


# Register MCP servers into ~/.claude/settings.json
cp aesop-xi/tools/claude-settings-mcp.json ~/.claude/settings.json
Step 3: Launch Local Memory Mesh
# Run master bootstrap launcher
bash aesop-xi/scripts/launch-memory-mesh.sh

4. Cloud Setup: Vertex AI Cross-Account IAM Handshake
To ground queries against the multi-gigabyte master corpus without carrying raw files in edge memory, route queries to Google Cloud Vertex AI while redirecting all costs to the personal $1,000 credit pool.
Step 1: Execute Bootstrap Handshake
# Run the automated cross-account handshake script
bash aesop-xi/scripts/gcp-cross-account-handshake.sh
Step 2: Grant Read-Only Storage Access
From the Google Cloud Console of the project holding the raw bucket (gs://business-secure-vault-bucket), run:
gcloud storage buckets add-iam-policy-binding gs://business-secure-vault-bucket \
  --member="serviceAccount:service-PERSONAL_PROJECT_NUMBER@gcp-sa-discoveryengine.iam.gserviceaccount.com" \
  --role="roles/storage.objectViewer"
Step 3: Create Vertex Data Store
1. Open Vertex AI Agent Builder > Data Stores under the Personal Project.
2. Select Cloud Storage -> Point to gs://business-secure-vault-bucket/.
3. Choose Unstructured documents with Continuous import.
4. Configure the local @google-cloud/vertex-search-mcp connector to query this datastore on demand.
