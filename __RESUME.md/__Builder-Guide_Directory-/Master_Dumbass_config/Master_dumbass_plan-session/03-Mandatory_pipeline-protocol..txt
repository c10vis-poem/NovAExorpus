1. The Ingestion Invariant: When you enter a task, the code doesn't send it to the LLM. It routes directly to OmniRoute. OmniRoute forces the parallel execution of Mem0, Terrestrial Brain, crg, and Graphify over your local repository files and Postgres database.
2. The ReasoningBank Filter: The raw text and database fingerprints are intercepted by ReasoningBank. ReasoningBank processes this algorithmically—using strict deterministic code rules, schema validation, and text distillation—to package a single, clean Markdown context string.
3. The Blind Agent Injection: The model is finally invoked, but it is fed only the pre-compiled, sanitized context packet generated by ReasoningBank. It has zero awareness of the raw logs or tool outputs. It has no choice but to compute a solution based only on the exact data you allowed through the filter.
4. The Output Quarantine: When the model outputs its code or execution payload, it doesn't print to your terminal or touch your workspace. It drops straight into the Continual Harness.
5. The Audit and Write-Back: The Continual Harness attempts to compile your APKs, runs local test parameters, and passes the execution logs to Task Observer. Task Observer codifies the entire trajectory, computes the success or failure states, and commits the records back down into the local PostgreSQL SHA-256 CAS data layer.
