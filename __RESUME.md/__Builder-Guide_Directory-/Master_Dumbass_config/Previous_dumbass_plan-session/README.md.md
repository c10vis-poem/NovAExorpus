_dumbass_universal_memory — Decoupled
Persistent Memory Core
System Role & Authority
Central cross-service persistent memory backbone connecting SQLite FTS5,
PostgreSQL + pgvector (OB1 / Terrestrial Brain), Mem0 episodic storage,
Reasoning Bank, and the OmniRoute Port 20128 asynchronous tap.
Architecture & Subsystems
●​ mem0/: Fast episodic context cache, session variables, habit tracking, and
user preferences.
●​ ob1_postgres/: Static Terrestrial Brain database schemas and pgvector
long-term invariants.
●​ reasoning_bank/: Active execution pathways and multi-agent plan
graphs.
●​ sqlite_fts5/: Local fast Code Review Graph (CRG) AST symbol indices
and blast-radius caches.
●​ omniroute_tap/: Gateway interceptor on Port 20128 performing
asynchronous prompt/response stream extraction.
●​ archive/: Historical traces and compacted memory snapshots.
Multi-Tier Memory Flow
1.​ Read Phase: Query Mem0, Terrestrial Brain, and CRG before execution.
2.​ Write-Back & Compaction: Commit short-term variables to Mem0,
permanent truths to Terrestrial Brain.
3.​ Obsidian Vault Sync: Mirror static memory events to /vault/memories/
with clean UUID/timestamp frontmatter.
