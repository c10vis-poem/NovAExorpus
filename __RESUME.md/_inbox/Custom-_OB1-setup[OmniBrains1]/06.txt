## OB1 — What It Actually Does

It's not "a Supabase Edge Function that stores facts." It's **an infrastructure layer** with:

- **One database** (Supabase/Postgres + pgvector) — stores thoughts as raw text, vector embeddings, and structured metadata
- **One AI gateway** (OpenRouter) — handles embeddings and LLM calls for the whole system
- **One chat channel** — input/output surface
- **MCP server** with 4 core tools: `search_thoughts`, `list_thoughts`, `thought_stats`, `capture_thought` + read-only aliases for ChatGPT
- **Agent Memory API** — runtime-neutral recall, write-back, review, inspector, and **recall-trace** API. This is a *governed* memory layer with provenance, use-policy, source-reference, relation, and **audit sidecars**
- **Schema-Aware Routing** — LLM-powered routing that distributes unstructured text across multiple database tables automatically
- **SHA-256 content-fingerprint dedup** via `upsert_thought` RPC
- **Prompt-injection sanitization** on every capture
- **Row Level Security** for multi-user isolation
- **Shared MCP Server** — scoped access to parts of your brain for others
