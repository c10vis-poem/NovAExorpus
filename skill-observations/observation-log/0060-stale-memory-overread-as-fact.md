**Issue:** A note recorded that stock tools were moot as "dropped". Later sessions treated that as settled, and the agent wrote it into subagent prompts as a hard rule, so three write-ups repeated it until the operator corrected it. The same session sent the operator to re-share files that searches had already shown were reachable.

**Suggested improvement:** Record the scope of a decision in the note (what was ruled out, what stays). Keep memory claims out of subagent rules unless they match recent documents.

**Principle:** A remembered decision is a claim with a scope. Check it against the newest source before making it a rule for others.
