name: multi-corpora-federation description: Use when an agent
plans or executes tasks spanning multiple specialized corpora
(Code, DevOps, Assets, Human Knowledge).
Multi-Corpora Federation Skill
The Four Corpora Taxonomy
1.​ Code Corpus: Abstract Syntax Trees (ASTs), interfaces, Kotlin services, Python
daemons.
2.​ DevOps / Infrastructure Corpus: Dockerfiles, runtimes, Tailscale configs, ADB
loopback setups.
3.​ Asset Corpus: Binary metadata, model weights (.gguf), UI layouts, media samples.
4.​ Human Knowledge Corpus: Markdown notes, specifications, tickets, release
changelogs.
Cross-Corpora Execution Heuristics
-​
Federated Entity Identity: Before altering code, verify that the concept is anchored in
the central semantic graph (_dumbass_universal_memory).
-​
Reactive Propagation: When a code change occurs in the Code Corpus, flag the
affected documentation notes in the Human Knowledge Corpus as requiring review.
-​
Cross-Layer Integrity: Never mix raw asset binaries into code trees. Reference assets
by hash or local URI pointer.
