"A Local Agentic Cognitive Architecture backed by an Open Memory Protocol
(OB1) and a Structured Markdown/JSONL Knowledge Pipeline."

conversational context, graph-based associative reasoning, structured semantic documentation,
and permanent relational storage.

4. Hybrid Cognitive Memory Engine (CME) Breakdown
The memory architecture organizes across four distinct temporal and functional states:

1.​ In-Context Short-Term Layer (mem0 + OmniRoute):
●​ mem0: Manages in-session rolling habits, dynamic user syntax preferences, and
short-term personalization.
●​ OmniRoute (http://localhost:20128/v1): Serves as both the unified data
routing gateway (directing requests across NPU, Jetson, and Cloud) and an


asynchronous memory tap extracting candidate reasoning paths into the
Reasoning Bank.
2.​ Structural Medium-Term Layer (wiki_md/):
●​ Implements Andrej Karpathy's Living LLM Wiki standard via OpenWiki TUI. A
compounding, human- and machine-readable Markdown second brain with
bidirectional [[wikilinks]].
3.​ Global Persistence Layer (OB1 / Open Brain):
●​ Nate B. Jones's OB1 protocol operating over PostgreSQL with pgvector via
MCP. Decouples memory from inference ("own the memory, rent the model") so
any model instantly inherits system knowledge.
4.​ Cognitive Execution History (reasoning_bank/):
●​ The system flywheel and epistemic ledger (active_execution_paths.json).
Stores how problems were solved, step-by-step logic trajectories, and RLVR
validation outcomes (+1.0 / -1.0) to ensure zero-loss crash recovery.


5. Master Orchestration & Execution Router
●​ Orchestrator Role: The central workflow router directing tasks based on complexity:
●​ Low-latency, bounded on-device tasks ➔ Local 0.8B/9B weights running on
Snapdragon Hexagon NPU.
●​ Intermediate compilation and local indexing ➔ Node Beta (NVIDIA Jetson Orin
Nano Super).
●​ High-compute frontier analysis ➔ Cloud providers via OpenRouter / Vertex AI.
●​ Tooling Integration: Integrates Everything Claude Code (ECC), Honey-for-Devs, AST
code dependency mappers (Graphify), and Matt Pocock prompt skills into modular,
repeatable execution environments.
