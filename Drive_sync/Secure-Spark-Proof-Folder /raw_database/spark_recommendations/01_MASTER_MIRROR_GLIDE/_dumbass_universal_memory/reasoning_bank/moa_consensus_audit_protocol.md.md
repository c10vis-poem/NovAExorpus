Mixture-of-Agents (MoA) Consensus Audit Protocol
Mined from: PLUGINS TOOLS AND MEMORY LAYER ARGUMENTS (Files 7, 11, and
'And I know I'm.txt')
Core Principle: Scope to High-Stakes Promotions
A single auditor model cannot reliably catch its own blind spots. A Mixture-of-Agents (MoA)
ensemble drawn from distinct model families catches architectural drift and hallucinated paths
before code or specs enter production.
Operational Scope
To prevent runaway compute costs, MoA consensus is strictly scoped to high-stakes
transitions:

1.​ Promoting a document from Pending ➔ Canon.
2.​ Any modification touching frozen/immutable paths (01_raw_sources/).
3.​ Overriding or modifying core security policies in aesop-xi/policies/.

Routine daily traffic runs through a fast single-pass check (0.8B / 9B).
Disagreement & Fail-Closed Rule
If the ensemble models split their verdict (e.g. 1 PASS, 1 FAIL):

●​ Automatic Fail-Closed: The candidate batch is quarantined immediately into
.incognito_red_sandbox/quarantine_logs/.
●​ Human-in-the-Loop Escalation: An alert is logged to UNRESOLVED.md for operator
review. No candidate batch self-promotes on a split vote.
