So: yes, every folder gets its own `README.md` (what it is) + `skill_manifest.json` (its skills) + `llm_wiki.md` (its wiki/state), and `global-documentation-vault` is the one exception — reference docs only, no manifest or wiki of its own since it's shared/read-only across every other repo.
