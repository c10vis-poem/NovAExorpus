—Droid DeX (often officially listed as Android-Dex or bundled via installers like DroidDesk) is
an excellent choice for the Samsung Galaxy Tab S9 FE. It handles the automated installation
scripts and leverages a built-in XFCE4 desktop with much smoother performance. [1, 2, 3]
Step 1: Disable Child Process Restrictions
This is the most critical step for compilation tasks like building Trusted Firmware-A. Without this,
Android will automatically shut down your Linux terminal if it uses too much background
processing power. [4]
1.​ Go back to your main Settings menu and tap the new Developer Options row at the
very bottom.
2.​ Scroll down until you find the "Disable child process restrictions" toggle (sometimes
labeled under App/Process management limits).
3.​ Turn this toggle ON.
4.​ While in this menu, turn USB Debugging to ON as well (this helps the display driver link
smoothly). [1, 4, 5, 6]
Step 2: Disable Battery Optimization
Ensure Android does not put your Droid DeX environment to sleep while you are coding.
1.​ Open Settings > Apps and find your Droid DeX / DroidDesk app.
2.​ Tap Battery and switch it from Optimized to Unrestricted. [4]
Step 3: Launching and Installing VS Code
Now you are ready to boot your Linux environment.
1.​ Open the Droid DeX app on your tablet.
2.​ Tap Setup Desktop Essentials and select XFCE4 to initiate the clean desktop
installation.
3.​ Once complete, tap Launch Desktop. Your screen will load into the XFCE4 graphical
workspace.
4.​ Pull up the Linux terminal browser or the app manager inside the desktop environment
and pull down the Linux ARM64 (.deb) archive directly from the Official Visual Studio
Code Download Page.
5.​ Install it directly through your terminal using:​
sudo dpkg -i <downloaded-vscode-package>.deb​
