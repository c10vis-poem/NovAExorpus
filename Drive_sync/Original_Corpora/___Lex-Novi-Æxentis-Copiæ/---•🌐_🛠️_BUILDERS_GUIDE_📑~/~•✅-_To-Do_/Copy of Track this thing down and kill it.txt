## Part 2: Automated Housekeeping Utility Script
Save this script inside Termux as master_build-guide/termux-building-skills/open-wiki-cli/system_housekeeper.sh and make it executable with chmod +x system_housekeeper.sh.
It sweeps all specified paths, checks your repository clean states, extracts un-tracked .txt or .md notes from Markor or Drive paths, and moves them into your central data staging yards for future conversion into structured .jsonl data sets.

#!/usr/bin/env bash# ==============================================================================# AESOP XI: REGULAR BI-DAILY SYSTEM HOUSEKEEPING & MAINTENANCE DAEMON# Script ID: AX-SYSTEM-HOUSEKEEPER-CORE# Status: READY_FOR_PRODUCTION_AUTOMATION# ==============================================================================
set -euo pipefail
# ------------------------------------------------------------------------------# 1. READ CONFIGURATION TARGETS FROM THE COGNITIVE REPOSITORY LAYER# ------------------------------------------------------------------------------
WORKSPACE_ROOT="/data/data/com.termux/files/home/master_build-guide"
MARKOR_DIR="/sdcard/Documents/Markor"
DRIVE_DIR="/data/data/com.termux/files/home/storage/shared"
STAGING_YARD="$WORKSPACE_ROOT/file-management-and-skills/target-docs-curation/unassigned-telemetry"

echo "================================================================================"
echo "🧹 [SYSTEM HOUSEKEEPER] Initializing Scheduled Multi-Layer Cleanup Pass..."
echo "================================================================================"
# Initialize an isolated curation landing directory for raw orphaned notes
mkdir -p "$STAGING_YARD"
# ------------------------------------------------------------------------------# 2. RUN SYSTEM SWEEP ACROSS MARKOR NOTE PACKAGES & MOBILE STORAGE# ------------------------------------------------------------------------------
echo "📝 Checking mobile Markor Note directories..."if [ -d "$MARKOR_DIR" ]; then
    # Locate files created or modified outside our strict git layout parameters
    find "$MARKOR_DIR" -type f \( -name "*.md" -o -name "*.txt" \) -mtime -1 | while read -r raw_note; do
        note_name=$(basename "$raw_note")
        echo "   📂 Discovered detached asset: $note_name. Harvesting for data curation yard..."
        # Safely move file to our staging zone without over-writing existing data files
        cp --backup=numbered "$raw_note" "$STAGING_YARD/"
        # Clear out original temp records to keep mobile paths clean
        rm "$raw_note"
    doneelse
    echo "   ⚠️  Markor note path not available or permission denied. Bypassing..."fi
# ------------------------------------------------------------------------------# 3. RUN DRIVE CONTAINER ENFORCEMENT MATCHES# ------------------------------------------------------------------------------
echo "🌐 Checking integrated Drive folders and workspace storage loops..."if [ -d "$DRIVE_DIR" ]; then
    find "$DRIVE_DIR" -type f \( -name "*.txt" -o -name "*.log" \) -size +1k | while read -r shared_file; do
        filename=$(basename "$shared_file")
        echo "   📦 Staging un-filtered information block: $filename"
        cp --backup=numbered "$shared_file" "$STAGING_YARD/"
        rm "$shared_file"
    donefi
# ------------------------------------------------------------------------------# 4. ITERATE OVER EXPANDED GITHUB REPOSITORIES AND AUDIT REPO STATES# ------------------------------------------------------------------------------
echo "🦅 Auditing all decentralized repository boundaries..."
cd "$WORKSPACE_ROOT"
# Iterate across all decoupled folder modules in the architecture treefor repo in horizons-ui-v1.2 termux-building-skills file-management-and-skills obsidian-vault-new nova-claw-runtime; do
    if [ -d "$repo" ]; then
        echo "   🔍 Scanning Git boundary repository: $repo"
        cd "$repo"
        
        # Enforce basic repository state evaluation safely locally
        if [ -d ".git" ]; then
            # Check for uncommitted source lines or untracked tool files
            UNTRACKED_COUNT=$(git status --porcelain | wc -l)
            if [ "$UNTRACKED_COUNT" -gt 0 ]; then
                echo "   ⚠️  UNCOMMITTED MUTATIONS LOGGED INSIDE: $repo ($UNTRACKED_COUNT files un-indexed)"
            else
                echo "   ✅ Repository clean and aligned."
            fi
        else
            echo "   📝 Layer tracking file active, but uninitialized on GitHub. Boundary secure."
        fi
        cd "$WORKSPACE_ROOT"
    fidone

echo "================================================================================"
echo "🎉 [SYSTEM HOUSEKEEPER] Daily data optimization sweep successfully executed."
echo "   All gathered asset logs deposited cleanly into: $STAGING_YARD/"
echo "================================================================================"

## Part 3: Deploying the Bi-Daily Automation directly via Termux
Because you are operating exclusively from your mobile phone node without an external scheduling OS framework, you can hook this sweeper directly into Termux's local background scheduling tools.
Run this command block inside your terminal shell to register your housekeeper daemon to run automatically inside your device runtime environment:

# 1. Update and grab the Termux scheduling package utilities
pkg install termux-services -y
# 2. Append execution anchors to your local terminal environment file # This runs a check every single time you spin up a terminal shell session,# catching any mutations that occurred while the shell was asleep.
echo "$WORKSPACE_ROOT/termux-building-skills/open-wiki-cli/system_housekeeper.sh" >> ~/.bashrc
# 3. Alternatively, link it to your automated local login routine# This guarantees your network spaces are cleanly swept without manual script execution.
echo "alias clean-mesh='$WORKSPACE_ROOT/termux-building-skills/open-wiki-cli/system_housekeeper.sh'" >> ~/.bashrc

echo "⚡ [LOCAL CODES] Automation hooks applied to your mobile shell environment profile."
