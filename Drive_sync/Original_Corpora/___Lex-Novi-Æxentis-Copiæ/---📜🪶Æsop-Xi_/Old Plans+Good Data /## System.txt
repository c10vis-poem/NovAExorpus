AESOP XI is a decentralized, self-healing multi-agent cognitive architecture operating across a heterogeneous peer-to-peer edge network (smartphones and developmental boards) with automated cloud-assisted optimization flywheels. ## 🧠 Core Component Catalog & Credits## 1. Intelligence & Frontend

* Horizon UI: A native Kotlin/Java APK providing the primary user interface. It acts as the visual dashboard for real-time monitoring and human-in-the-loop task governance.
* Novus Agenti: The cognitive core combining Mixture-of-Experts (MoE) and Mixture-of-Agents (MoA) topologies. It decouples tasks into parallel planning operations before execution.

## 2. The Omni Claw Runtime

* Omni Claw: A hardware-abstracted runtime utilizing local phone daemons, dev board background services, native SDKs, and cloud API connectors. It acts as the automated "hands" of the system, executing actions directly on target devices without human interface requirements.

## 3. The Tri-Tailed Memory Fabric & Context Routing

* Open Brain Protocol (OB1): Built on Nate B. Jones's foundational open-brain repository. It operates as the centralized local Postgres vector database backend and Model Context Protocol (MCP) server. It decouples your global context from specific LLM instances, allowing you to swap models while retaining permanent historical data alignment.
* Omni Route: The dynamic context router. It evaluates model output mid-inference to determine the optimal memory path required (e.g., whether to fetch a temporal token, a localized markdown link, or a heavy analytical document).
* Tier 1 Memory (Episodic): mem0 — An open-source agent memory layer that tracks shifting user habits, ambient preferences, and micro-context states across real-time interactions.
* Tier 2 Memory (Structural): LLM Wiki, Open Wiki CLI & Obsidian Skills — The grounding repository. Agents manage their own second brain in markdown format (.md). During bootstrap and early development phases, this is managed via an Open Wiki CLI terminal utility to audit the vault network before it syncs via P2P to the local Obsidian Vault infrastructure.
* Tier 3 Memory (Analytical): notebooklm-py & Graphify — Structured graph-relational parsing via Graphify coupled with Teng Lin's notebooklm-py tool. It automates Google's backend APIs to dynamically spin up and populate high-capacity Gemini Notebook contexts for heavy log analysis, bypassing local resource constraints.
* Reasoning Bank: A dedicated cryptographic and logical storage ledger. It saves intermediate agent chain-of-thought pathways, letting models resume complex problem-solving routines without restarting the entire inference loop.

## 4. The Adversarial Self-Healing Data Flywheel

* Isolated Red Agent Auditor & Nope Data Bank: An out-of-band, air-gapped security container. It intercepts all raw tool inputs, model responses, and terminal executions. It reviews them against the "Nope Data Bank" to block security exploits or logical loops.
* Recursive KAG Pipeline: Validated traces from the Red Agent are formatted into .jsonl files and compressed markdown, then streamed to Google Cloud Platform (GCP) storage buckets. This data feeds automated recursive Knowledge-Augmented Generation (KAG) pipelines, continuously fine-tuning the underlying models on your specific operational history.
