Claude saves skills as folders containing a main file named SKILL.md.
They are labeled using YAML frontmatter metadata at the top of the file
and plain Markdown for instructions. \[1, 2, 3\]

## **Storage Locations and Saving**

- **Personal storage:** Saved locally in ~/.claude/skills/ for use
  > across all your projects.

- **Project storage:** Saved in .claude/skills/ inside a specific
  > repository.

- **Web/Desktop app:** Uploaded as a zipped folder via the capabilities
  > settings menu. \[2, 3, 4, 5\]

## **Labeling and File Structure (SKILL.md)**

- **YAML Frontmatter:** Placed between triple dashes (---) at the top of
  > the file to define triggers and descriptions.

- **Directory name:** The name of the folder acts as the command name
  > (e.g., typing /skill-name).

- **Markdown body:** Standard Markdown headings and text below the
  > frontmatter contain the precise execution steps. \[1, 3, 6\]
