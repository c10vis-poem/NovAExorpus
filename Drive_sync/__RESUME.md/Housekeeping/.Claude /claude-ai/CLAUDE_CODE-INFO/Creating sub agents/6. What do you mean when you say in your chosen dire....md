When I said "your chosen directory," I was referring back to the two
locations from Step 1. It just means you need to decide *where* you want
this custom subagent to live based on how you plan to use it.

You have two choices:

**1. The Project Directory (\<project-root\>/.claude/agents/)**

Choose this if you want the subagent to only exist for a specific
project.

- **Why use it:** If you are working on a specific web app, you might
  > create a subagent that only knows about that app's specific coding
  > guidelines. You can commit this file to Git so everyone else working
  > on the repo gets access to the exact same subagent.

**2. The User Directory (~/.claude/agents/)**

Choose this if you want the subagent available globally across your
entire machine, no matter what folder you are working in.

- **Why use it:** If you want a general-purpose assistant—like a
  > subagent designed specifically to write bash scripts or format JSON
  > data—putting it in your home directory ensures you can trigger it in
  > any project without having to copy the file around.

So, "your chosen directory" just means picking whichever of those two
paths fits what you are trying to build.
