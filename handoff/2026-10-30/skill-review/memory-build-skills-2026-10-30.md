# Skills to attach to the memory and design build (2026-10-30)

This is a new standalone list. No existing file was changed.

**How it was made:**
- A keyword filter cut the 1,588 skills on the account down to **358 candidates** (memory, graph, SQLite, vector, MCP server, wiki, Obsidian, schema, index, compaction, handoff, harness, retrieval, reverse engineering, Supabase, Cloudflare, Next.js).
- 4 Sonnet subagents read each candidate's SKILL.md **in full**: 358 of 358. They did not open references/ files.
- Each skill was scored against the builder request (`memory-design/nvaex-memory-builder-request-2026-10-30.md`):
  - **3** = attach it to design sessions;
  - **2** = a useful part or guidance;
  - **1** = a minor idea;
  - **0** = no help.
- "Conflicts" names any behavior that breaks The Builder's rules.

**Results:** fit 3: 4, fit 2: 57, fit 1: 148, fit 0: 149.
