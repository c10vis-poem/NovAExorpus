### Integrations synthesis (facts only — no decisions)
- Two incompatible code families share one repo: **UUID family** (server/, agent-memory-api, open-brain-rest, hermes-agent-memory, openclaw plugin, update/delete-thought-mcp, entity-extraction-worker) matches docs/01's schema; **integer/`thought_id` family** (enhanced-mcp, smart-ingest, rest-api, consolidation-workers, schemas/smart-ingest, kubernetes init.sql BIGSERIAL) does not. Verified at `schemas/enhanced-thoughts/schema.sql:437` (returns `{id, fingerprint}`).
- Every OB1 LLM/embedding call hardcodes `openrouter.ai` / `api.openai.com` / `api.anthropic.com` base URLs. Only kubernetes-deployment exposes `EMBEDDING_API_BASE`/`CHAT_API_BASE`. Routing through OmniRoute means patching the fork.
- Importance scales in play: 1–5 (column, smart-ingest), 0–6 (classifier, rest-api update, consolidation), 0–100 (enhanced upsert, open-brain-rest).
- Supersession: three mechanisms (provenance-chains column, typed-reasoning-edges edge, smart-ingest `metadata.supersedes`), and hard deletes in delete-thought-mcp, open-brain-rest, rest-api, dedup-resolve.
- `_shared/helpers.ts` exists in 4 divergent versions; no single copy has all the hardenings.
- Auth: header-only + constant-time in enhanced-mcp, rest-api, smart-ingest; `?key=` + plain compare everywhere else.
- Ready-made runtime arms: Hermes (Python MemoryProvider, has route bugs), OpenClaw (TS plugin, build broken at HEAD), Chrome (MV3), Telegram/Slack/Discord (capture only). None for Claude Code, dsh or OmniRoute.

## OB1 read complete (2026-09-29)

Every text file in `c10vis-poem/OB1` @ `238df6c` is now read and has a row here. The skipped files are lockfiles and binaries, each listed in its row. Facts only; decisions belong to the grill.

- **No single canonical model.** The fork has at least 5 `thoughts` shapes, 3 `upsert_thought` signatures, and both a uuid family and an integer `thought_id` family.
  - dashboard-pro, rest-api and several importers belong to the integer family.
  - dashboard-next, open-brain-rest and the enhanced schema belong to the uuid family.
- **Importance has no single scale.** 1–5 (the enhanced column default and its search ranking), 0–6 (the classifier, rest-api and dashboard-pro), 0–100 (the enhanced upsert, open-brain-rest and the dashboard-next kanban). Editors silently clamp stored values.
- **Sensitivity is enforced only in the UI.** Capture, enrichment and search send content to a hardcoded openrouter.ai before any sensitivity check. The restricted lock is client-side or bypassable (dashboard-next connections route). The exception worth copying is weekly-digest's fail-closed filter.
- **Auth is almost always one shared key.** Many servers accept it as `?key=` in the URL; some servers have no auth at all. There is no per-user or per-workspace scoping except RLS, which is bypassed because the servers run as service_role.
- **Many features don't work end to end against the fork's own schemas.** Examples: the `derived_from` edge in wiki-synthesis, `pending_confirmations`, `reflections`, `find_near_duplicates`, dry-run ingest, and the `result.thought_id` / `result.action` reads.
