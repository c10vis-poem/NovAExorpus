### Integrations synthesis (facts only — no decisions)
- Two incompatible code families share one repo: **UUID family** (server/, agent-memory-api, open-brain-rest, hermes-agent-memory, openclaw plugin, update/delete-thought-mcp, entity-extraction-worker) matches docs/01's schema; **integer/`thought_id` family** (enhanced-mcp, smart-ingest, rest-api, consolidation-workers, schemas/smart-ingest, kubernetes init.sql BIGSERIAL) does not. Verified at `schemas/enhanced-thoughts/schema.sql:437` (returns `{id, fingerprint}`).
- Every OB1 LLM/embedding call hardcodes `openrouter.ai` / `api.openai.com` / `api.anthropic.com` base URLs. Only kubernetes-deployment exposes `EMBEDDING_API_BASE`/`CHAT_API_BASE`. Routing through OmniRoute means patching the fork.
- Importance scales in play: 1–5 (column, smart-ingest), 0–6 (classifier, rest-api update, consolidation), 0–100 (enhanced upsert, open-brain-rest).
- Supersession: three mechanisms (provenance-chains column, typed-reasoning-edges edge, smart-ingest `metadata.supersedes`), and hard deletes in delete-thought-mcp, open-brain-rest, rest-api, dedup-resolve.
- `_shared/helpers.ts` exists in 4 divergent versions; no single copy has all the hardenings.
- Auth: header-only + constant-time in enhanced-mcp, rest-api, smart-ingest; `?key=` + plain compare everywhere else.
- Ready-made runtime arms: Hermes (Python MemoryProvider, has route bugs), OpenClaw (TS plugin, build broken at HEAD), Chrome (MV3), Telegram/Slack/Discord (capture only). None for Claude Code, dsh or OmniRoute.
